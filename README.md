# AIX Account Takeover Demo

A Livin'-style Android mockup for the AIX Phase III kiosk.

## What it demonstrates
- The **bank owns the risk decision**: allow, step-up or block.
- AIX requests only governed **assurance outcomes** from operators: Number Verify, SIM Swap and device/location verification.
- No raw subscriber data, profile, messages or location history leaves the supplier boundary.
- AIX creates a **Trusted Decision Receipt** and a metered, attributable successful decision.

## Build
Every push to `main` runs **Build ATO Demo APK**. Download `livin-ato-aix-demo-apk` from the Actions artifact.
